# Cinematic Streaming Tracker 🎬

A premium, minimalist TV show tracker built with HTML, CSS (Glassmorphism), and Vanilla JavaScript.

## Features
- **Global Search:** Find any TV show using the TMDB API.
- **Triple Rating System:** View ratings from TMDB, IMDb, and Trakt.tv simultaneously.
- **Custom Tracking:** Manage shows in Watchlist, Watching, Downloaded, Completed, or Dropped status.
- **Modern UI:** Glassmorphism design, smooth animations, and a sophisticated Dark/Light mode toggle.
- **Responsive:** Optimized for both desktop and mobile devices.

## How to Run
Simply open `index.html` in any modern web browser.
