# 📺 New Shows Tracker

A comprehensive, interactive web application designed to help users track, discover, and organize the latest TV shows from top streaming platforms. Built with a sleek, cinematic Dark Mode UI.

## 🚀 Live Demo
**[🎬 Click here to view the live website!](https://ahmad2681a1.github.io/shows-tracker/)** ## ✨ Core Features

* **🍿 Platform Filtering:** Instantly browse the latest shows from major networks including Netflix, Amazon Prime, HBO, Apple TV+, Hulu, and Disney+.
* **🔍 Smart Search:** Quickly search for any TV show globally by its title.
* **📊 Advanced Sorting:** Sort TV shows by Most Popular, Newest Release, or Highest Rated.
* **📋 Interactive Details Modal:** Click on any show to open a cinematic modal featuring:
  * High-quality poster.
  * Precise details (Release Date, Current Status, Number of Seasons).
  * Reliable ratings from **TMDB** and **IMDb**.
  * A comprehensive plot overview.
* **▶️ Integrated Trailers:** Automatically fetches and plays the official YouTube trailer or teaser for the selected show.
* **❤️ Personal Favorites:** Allows users to save shows to a custom "My Favorites" list using local storage, keeping data safe even after the browser is closed.
* **🔄 Smart Recommendations:** Displays a "You Might Also Like" section inside the modal with clickable posters of similar shows.
* **⬇️ Seamless Pagination:** A "Load More" feature to continuously fetch new pages of shows without refreshing the site.

## 🛠️ Tech Stack & APIs

* **Front-End:** HTML5, CSS3, Vanilla JavaScript.
* **UI/UX:** Fully responsive, cinematic Dark Mode design.
* **APIs Used:**
  * **[TMDB API](https://www.themoviedb.org/):** Primary source for fetching show data, posters, recommendations, and YouTube trailer links.
  * **[OMDb API](https://www.omdbapi.com/):** Secondary API integrated specifically to fetch highly accurate IMDb ratings.
* **Storage:** HTML5 `localStorage` for the Favorites feature.
* **Hosting:** Deployed seamlessly via GitHub Pages.

## ⚙️ How to Run Locally
1. Clone the repository: `git clone https://github.com/ahmad2681a1/shows-tracker.git`
2. Open the folder and double-click `index.html` to run it in your browser. No installation or build process required!
